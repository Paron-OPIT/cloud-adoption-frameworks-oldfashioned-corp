# Cloud Adoption and Modernization Strategy – OldFashioned Corp. (Academic project)

## Project Overview

This project presents a cloud adoption and modernization strategy for OldFashioned Corp., a fictional European leather goods manufacturer undergoing a major digital transformation.

The objective is to develop a comprehensive cloud strategy that addresses the company's existing IT challenges while establishing a secure, scalable, resilient, and cost-effective cloud environment.

The proposal is based on the **AWS Cloud Adoption Framework (AWS CAF)** and incorporates cloud architecture best practices, governance principles, security considerations, and a phased migration roadmap.

## Business Challenges

The proposed transformation addresses several key challenges:

- Legacy on-premises infrastructure.
- Limited scalability and infrastructure flexibility.
- Security and governance gaps.
- Modernization requirements for existing business applications.
- Availability and disaster recovery requirements.
- Inefficient software delivery and deployment processes.

## Proposed Cloud Strategy

The project explores an AWS-based target environment, focusing on the following areas:

- **Cloud Infrastructure:** Modernization of existing infrastructure and workloads using AWS services.
- **Architecture:** Design of a scalable, highly available cloud architecture.
- **Security:** Identity and access management, encryption, network security, and centralized monitoring.
- **Governance:** Multi-account strategy, organizational policies, and cloud governance.
- **High Availability & Disaster Recovery:** Resilience, backup strategies, and recovery planning.
- **CI/CD:** Automated software delivery and deployment pipelines.
- **Migration Roadmap:** A phased approach to cloud adoption and infrastructure modernization.
